# Support

## Community support

Use [GitHub Discussions](https://github.com/infercrane/infercrane/discussions) for installation,
configuration, architecture, and usage questions. Search existing discussions and documentation
before opening a new topic. Include the InferCrane version, operating system, provider, runtime,
deployment mode, sanitized command, and relevant content-free operation events.

Use [GitHub Issues](https://github.com/infercrane/infercrane/issues) for reproducible defects and
scoped feature proposals. GitHub Issues are not an incident-response channel or a support SLA.

## Security and private data

Never post credentials, customer prompts, model responses, private endpoint URLs, or suspected
vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md) to report a vulnerability through a
private GitHub security advisory.

## Commercial support

Community support is available through GitHub Discussions and Issues. Hosted-console access does
not include an SLA. For a design-partner deployment or contractual support conversation, contact
[hello@infercrane.com](mailto:hello@infercrane.com). Public documentation must not represent an
informal design-partner engagement as an SLA.
