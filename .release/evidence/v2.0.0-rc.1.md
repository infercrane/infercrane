  binding/target/cache hints while explicitly reporting `durable_kv: false`.

- API, CLI, generated Python/TypeScript SDKs, OpenAPI, Mintlify, migration, and context agree.
- `make dev-check-full`, clean-tree `make qualify-rc`, and `make qualify-contracts` passed at the
  implementation commit. Evidence is under `.infercrane/qualification/1886ab89e89a811707c546693bb5aa5141f89ba2`
