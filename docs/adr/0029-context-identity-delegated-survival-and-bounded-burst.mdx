# ADR 0029: Context identity, delegated survival, and bounded burst

InferCrane owns bounded logical session identity, expiry, and best-effort route hints. Reliability overrides
affinity and the data path reads only immutable/in-memory route and passport snapshots. Engines own KV.
Request survival is therefore a qualified delegated capability, not a control-plane implementation.

Burst Guard extends the existing governed fallback and admission contracts. It evaluates fresh evidence,
sustained thresholds, external health, and an explicit incremental cost ceiling. It neither creates a second
router nor bypasses privacy acknowledgement or hard budget reservation.
