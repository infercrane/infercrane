# ADR 0027: Privacy-preserving replay and observed capacity

## Decision

InferCrane persists bounded workload-shape traces containing relative arrival time, latency, token counts,
operation, streaming state, pseudonymous session/prefix relationships, and optional tool-pause timing.
Prompt bodies, outputs, tool arguments, and raw session identifiers are excluded. Pseudonyms use a
tenant-secret HMAC so equal public identifiers cannot be correlated across tenants.

Artifact cache state is a bounded observation with source and expiry. Prefetch is an idempotent intent
delegated to an infrastructure adapter and never implies completion. Capacity Intelligence aggregates
only tenant-scoped observed operations and always exposes the window and sample count.

## Consequences

Replay can test workload geometry while limiting content exposure, but it cannot prove semantic output
quality. Capacity history can inform later recommendations, but sparse or stale observations remain weak
evidence. Provider-native caches are reused instead of creating another artifact-transfer system.
