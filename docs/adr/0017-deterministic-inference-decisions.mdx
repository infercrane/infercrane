# ADR 0017: Persist deterministic inference decisions

Status: Accepted

## Context

Benchmark history, compatibility declarations, capacity observations, and external fallback existed
as separate facts. Choosing infrastructure from incomplete facts would fabricate confidence, while
queue overflow without hysteresis could oscillate traffic and spend external budgets unpredictably.

## Decision

Persist deployment SLO policy, canonical recommendation inputs and outputs, expiring capacity
evidence, overflow state, and every material overflow decision in PostgreSQL. A material decision is
a route/action, reason, or hysteresis-counter transition; identical steady-state observations are
coalesced to prevent unbounded audit growth. The recommendation algorithm is
versioned and advisory. Missing policy-required evidence makes a candidate ineligible.

Queue overflow requires an explicit external target, privacy acknowledgement, model mapping, hard
request and cost budgets, consecutive breach/recovery observations, fresh queue evidence, and
cooldown. Reconciliation publishes one primary or external route snapshot. The gateway continues to
route from memory and consumes a lease before transmission; it never reads PostgreSQL, duplicates
traffic, or retries a partially sent stream.

## Consequences

Operators can reproduce why a configuration or route was selected. Unknown price and capacity stay
unknown. External overflow is deliberately conservative. v0.7 does not perform semantic routing,
weighted spillover, or autonomous apply.

## Alternatives

An LLM planner was rejected because promotion and spending decisions must be deterministic. A new
request router was rejected because existing routers and provider endpoints own distribution.
Synchronous database checks in the gateway were rejected to preserve data-plane availability.

## Verification

Decision and overflow unit simulations, PostgreSQL migration tests, API/CLI/SDK/Terraform contracts,
reconciliation simulations, gateway no-replay tests, and Docker qualification form the evidence.
