A scenario passes only when its invariant and cleanup evidence are recorded. Registration means an
adapter exists; qualification states exactly what environment has exercised it.

## Qualification tiers

| Tier | Environment | Evidence |
| --- | --- | --- |
| Unit/contract | Go race tests and deterministic provider CLIs | Policy, translation, adoption, idempotency, redaction |
| Store | Disposable PostgreSQL | Leases, tenant isolation, migrations, restart recovery |
| Stack | Isolated Docker Compose | API/CLI, routing, streaming, cancellation, dashboard, SDKs |
| Cluster | Disposable Kind | Kubernetes ownership, SSA conflict, repair, restart, deletion |
| Package | Native archives and production image | Version, completion, clients, checksums, SPDX SBOM |
| Provider | RunPod, AWS BYOC, and a GPU Kubernetes cluster | Capacity, runtime, traffic, disruption, cost signals, zero inventory |

Local simulation never becomes real-provider evidence. Real qualification is bounded to the
declared replica count, requires an explicit paid-resource flag, and runs once against the frozen RC.

## Lifecycle invariants

| Scenario | Required invariant |
| --- | --- |
| Concurrent/replayed deploy | One durable operation, intent, revision, and provider resource per ordinal |
| CLI disconnect | The client can exit; the durable operation continues and can be resumed |
| Control-plane restart | The lease is recovered without a second provider create |
| Lost create response | Reconciliation adopts by deterministic external key |
| Router publish | New requests use the new generation; existing streams finish on the old one |
| Scale `1 → N → 1` | Every intent and decision is persisted, explained, withdrawn, drained, and deleted |
| Bad candidate | Release Guard deterministically rejects it while the active route remains serving |
| Post-promotion regression | Persisted monitor triggers the configured rollback exactly once |
| Delete restart | Withdrawal and provider deletion resume until direct absence is observed |
| Cancellation | Client disconnect is harmless; explicit cancellation is durable and auditable |

## Runtime and data-plane matrix

Real AWS, GCP, and Kubernetes qualification exercises vLLM, SGLang, and one immutable custom OCI
workload. Each must pass readiness, buffered chat, streaming, bounded benchmark, deletion, and
provider inventory. vLLM additionally proves named tool choice and strict structured output with a
qualified model/runtime configuration. Unsupported runtime features must be declared rather than
emulated by InferCrane.

RunPod additionally proves provider-native Serverless from zero, warm reuse, scale-to-zero, a
second cold start, streaming cancellation, endpoint adoption after a lost create response, and
endpoint deletion. Provider-hidden cold-start boundaries stay unavailable.

## Security and privacy

- Production starts as a non-root user, drops Linux capabilities, enables no-new-privileges, and
  contains no development fake.
- Provider credentials are external references or read-only mounts and never enter persisted
  provider metadata, logs, reports, or images.
- PostgreSQL, API, provider, tenant, audit, external-capacity, and passport boundaries have negative
  tests, not only successful-path tests.
- Prompt and output content are not persisted by default.
- External fallback requires opt-in, privacy acknowledgement, atomic request/cost reservations,
  bounded signals, and no retry after bytes may have left the controlled path.

## Operator budgets

These are qualification timeouts, not product latency claims. Provider allocation, image transfer,
artifact download, runtime initialization, and readiness remain distinct states wherever evidence
exists.

| Boundary | Default qualification timeout |
| --- | --- |
| Local control-plane readiness | 3 minutes |
| Real runtime readiness | 45 minutes |
| Provider resource deletion | 15 minutes |
| RunPod scale down | 10 minutes |
| Benchmark request | 35 minutes |

Do not repeatedly extend an ambiguous timeout. Inspect the persisted intent and direct provider
inventory, then resume the same run ID or clean it up.
