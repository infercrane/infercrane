# v1.0.0 — multi-provider release candidate

## Outcome

The automated implementation is a coherent, upgradeable multi-provider production platform ready
for one consolidated manual infrastructure qualification.

## Scope

- complete regression, migration, security and compatibility hardening
- documented upgrade/deprecation/support policy
- clean install, packages, checksums, SBOM/provenance where tooling is available
- consolidated acceptance harness for RunPod, AWS, vLLM, SGLang, OCI, serverless, elastic,
  fallback, disruption, rollback and zero-resource inventory
- documentation completion and release evidence audit

## Exclusions

No stable/public release, hosted control plane, managed compute, billing, or post-launch milestone.

## Acceptance

Every automated gate passes on one clean commit and `v1.0.0-rc.1` is annotated locally. All paid
provider gates remain visibly `DEFERRED`, and one bounded, resumable, cleanup-guarded manual workflow
is produced for final qualification.
