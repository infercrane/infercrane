# v1.7.0 — Evidence-backed recipes and Inference Lab

## Acceptance

- Recipe capture requires an immutable artifact, active explicit runtime version, and matching benchmark.
- Canonical payload/provenance has a stable SHA-256 digest and name/version cannot be rebound.
- Recipe search is tenant-scoped through API, CLI, Python, and TypeScript.
- Lab compares persisted model evidence without provisioning and persists canonical input/results.
- Every result carries an explicit evidence class; v1.7 emits measured only.
- Missing TTFT, throughput, SLO, or cost remains unavailable rather than estimated.
- Prompt and output bodies never enter recipe or Lab schemas.
- Historical migrations and all earlier release gates pass.

## Exclusions

No recipe marketplace, unverified built-in catalog, hidden paid run, custom load generator, fabricated
pricing, autonomous deployment, cross-tenant aggregation, or modeled performance claim.
