# v0.6.0 — portable runtimes

## Outcome

Users can bring a qualified OCI inference workload, and SGLang proves Runtime Contract V1 is real.

## Scope

- immutable OCI image digests and explicit protocol/port/readiness contracts
- telemetry, cancellation, drain and graceful shutdown contracts
- compatibility probing without executing untrusted build logic in the control plane
- SGLang adapter and pinned qualification profiles
- public runtime capability matrix

## Exclusions

No custom container engine, image-build service, arbitrary code sandbox, TensorRT-LLM, or claim that
all OpenAI-compatible images are equivalent.

## Acceptance

Required automated evidence:

- custom workload schema rejects mutable images, shell ambiguity, unknown protocols, invalid ports,
  nonstandard probes, missing cancellation/drain semantics and unbounded shutdown grace
- immutable workload identity and argv survive API submission, initial revision persistence,
  candidate revision canonicalization and provider replay
- provider adapters translate the workload to digest-pinned container execution without losing argv
  boundaries; the qualified AWS path uses direct Docker and the SkyPilot translation remains a
  hermetic contract fixture until an SSH-compatible image profile exists
- SGLang and custom OCI are selected through runtime/provider registries, never engine conditionals
  in lifecycle core
- deterministic HTTP fixtures prove readiness and model identity plus declared buffered, streaming,
  cancellation, drain and telemetry boundaries
- the exact runtime/provider/mode compatibility matrix is available through API/CLI and docs
- unsupported provider/mode/autoscaling combinations fail before provider mutation
- OpenAPI, Python, TypeScript, Terraform runtime selection, examples, docs navigation and links pass
  drift checks
- complete local and isolated Docker qualification pass on the exact clean commit

Real SGLang/GPU and custom-image evidence remains `DEFERRED`; simulated/local evidence must never be
described as real qualification.

## Implementation record

The v0.6 implementation adds `internal/runtimecontract`, immutable workload persistence, generic
provider translation, SGLang and custom OCI profiles, an exact compatibility inventory, conformance
fixtures, API/SDK surfaces and same-milestone docs. The control plane still delegates container
execution to provider mechanisms and does not build or inspect untrusted images.
