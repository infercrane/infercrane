# v1.4.0 — overload protection and durable async inference

## Acceptance

- database-free endpoint admission enforces concurrency, queue, timeout, size, output and priority;
- tenant request/token quotas and external budgets retain their existing owners;
- buffered internal retries are bounded; streaming and external requests are not replayed;
- async payloads and results are never persisted in plaintext;
- submission is idempotent and terminal disconnect-safe;
- leases are adoptable and stale completion is fenced;
- deadlines, cancellation, expiry and delivery attempts are persisted;
- completion webhooks are signed and SSRF-hardened;
- PostgreSQL/race, API drift, CLI, Docker and regression gates pass.

Real provider/runtime qualification is deferred to the consolidated manual qualification workflow.
