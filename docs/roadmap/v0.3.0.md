# v0.3.0 — secure BYOC and governed external capacity

## Outcome

Teams can operate a narrow AWS BYOC deployment and explicitly use external OpenAI-compatible
capacity without losing tenant isolation, auditability, privacy control or budgets.

## Scope

- organizations/projects/environments only where the domain model requires them
- scoped service credentials, secret references, RBAC and audit foundation
- external OpenAI-compatible target contract and OpenRouter adapter
- explicit health fallback with privacy disclosure and hard request/cost limits
- AWS EC2 BYOC adapter: role assumption, VPC/network inputs, immutable image, tags, reconciliation,
  orphan discovery and trustworthy cost metadata

## Exclusions

No EKS, SageMaker-wide abstraction, billing marketplace, semantic/LLM routing, silent shadowing,
managed compute, or automatic unbounded fallback.

## Acceptance

Security boundaries have adversarial tests; external routing is opt-in and persisted; the AWS
adapter passes Provider Contract V1 hermetically. Real AWS and external billing acceptance remain
`DEFERRED` until final manual qualification.

### Security and tenancy

- `tenant` remains the organization security boundary; no unused organization/project/environment
  hierarchy is introduced
- service accounts have role-bounded explicit scopes, one-time credentials, rotation, revocation,
  tenant isolation and complete audit attribution
- secret records persist references and metadata only; resolvers never return values through APIs,
  CLI output, logs, audit payloads or qualification evidence
- authorization denies unknown roles/scopes and cross-tenant resource identifiers without revealing
  whether another tenant owns them

### Governed external capacity

- an external target requires an explicit provider adapter, secret reference, privacy acknowledgement,
  model mapping and enabled policy
- health-based fallback occurs only before a request is sent; streaming requests are never replayed
- hard request and cost-reservation budgets are atomically consumed before external transmission;
  unknown pricing fails closed when a cost budget is configured
- policy, budget consumption, provider selection and denial reason are persisted and explainable
- OpenRouter is a configured OpenAI-compatible adapter, not a marketplace or billing reseller

### AWS EC2 BYOC

- one adapter owns EC2 translation and composes through Provider Contract V1
- the deployment requires region, subnet, security groups, AMI, immutable OCI image digest and
  instance type; defaults never silently select a public network
- role assumption uses short-lived credentials; no returned credential reaches logs or durable state
- `RunInstances` uses the durable replica key as an idempotency token and ownership tags
- observation, deletion and orphan inventory are tag-scoped and replay safe
- cost is `unknown` unless a timestamped, provenance-bearing source supplies it
- hermetic conformance covers lost responses, timeouts, adoption, deletion and redaction

### Documentation and evidence

- CLI/API, security, external target, OpenRouter, AWS setup, troubleshooting and migration docs are
  updated with copyable examples and explicit deferred states
- `.release` evidence is commit-addressed; real AWS/OpenRouter/RunPod evidence remains `DEFERRED`
