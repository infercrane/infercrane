# InferCrane v1.8.0-rc.1

v1.8 adds privacy-preserving Inference Replay, provider-native artifact placement contracts, and
tenant-scoped Capacity Intelligence. Replay is capture-only by default; explicit execution reuses AIPerf
and requires cost acknowledgement. InferCrane never stores prompt or output content for replay.

This local release candidate does not claim real-cloud cache or capacity qualification.
