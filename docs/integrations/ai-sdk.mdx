---
title: Vercel AI SDK
description: Use InferCrane model APIs with generateText, streamText, tools, and structured output.
---

The Vercel AI SDK's OpenAI-compatible provider connects directly to an InferCrane Model API,
dedicated deployment, or self-hosted gateway.

## Install

```bash
npm install ai @ai-sdk/openai-compatible
```

Configure the API key in a trusted server environment:

```bash
export INFERCRANE_API_KEY=your_api_key
```

## Stream text

```ts
import {createOpenAICompatible} from '@ai-sdk/openai-compatible';
import {streamText} from 'ai';

const infercrane = createOpenAICompatible({
  name: 'infercrane',
  apiKey: process.env.INFERCRANE_API_KEY,
  baseURL: process.env.INFERCRANE_BASE_URL ?? 'https://api.infercrane.com/v1',
  includeUsage: true,
});

const result = streamText({
  model: infercrane('qwen3.8-27b'),
  prompt: 'Explain prefix caching in three sentences.',
});

for await (const text of result.textStream) {
  process.stdout.write(text);
}
```

`includeUsage` requests final token usage for streaming calls so applications can reconcile usage
with InferCrane receipts.

## Connect a private endpoint

```ts
import {createOpenAICompatible} from '@ai-sdk/openai-compatible';

const infercrane = createOpenAICompatible({
  name: 'infercrane',
  apiKey: process.env.INFERCRANE_API_KEY,
  baseURL: process.env.INFERCRANE_BASE_URL,
});
```

Use this form for a private canary, a dedicated deployment, or a regional InferCrane endpoint. Keep the credential in server code and never expose it in a browser bundle.

The repository also contains a dedicated `@infercrane/ai-sdk-provider` adapter. It remains a source
preview until its first npm release; the standard adapter above is the supported install path today.
