# Replay and capacity intelligence

Inference Replay records the timing and token-count shape of production traffic without storing prompt
or output bodies. Session, parent-session, and shared-prefix identities are tenant-secret HMACs, not raw
identifiers. A trace records its window, sample count, schema, canonical digest, and evidence class.

```bash
infercrane replay coder-production --window 24h --max-requests 1000
```

A capture keeps at most `--max-requests` requests, newest first. When the window held more, the
trace sets `request_limit_reached` to `true`: its requests cover less time than the window. It is
`false` when every request in the window was kept, and `null` for a trace captured before this was
recorded. An optimization report uses it to project monthly cost over the time the kept requests
cover.

A trace can also be captured from an endpoint's requests, or from one binding of it, such as a closed
API routed through InferCrane, which has no deployment:

```bash
infercrane migrate capture support-bot --binding primary --window 24h
# POST /api/v1/endpoints/support-bot/replays {"binding":"primary","window_seconds":86400}
```

Such a trace names `endpoint_id`, `endpoint_name`, and `binding_id` instead of a deployment, and is
listed by `GET /api/v1/endpoints/{name}/replays`. Every trace records, per request, the time to
first token and the cached input tokens when the upstream reported them. `POST
/api/v1/endpoints/{name}/traffic-observations` imports observations the same way the deployment
route does, with an optional `binding` and `cached_input_tokens`, so a closed API's own logs can
become a trace. See [Migrate from a closed API](/features/migration).

This command only captures persisted observations. It sends no workload and creates no infrastructure.
To approximate the captured mean token sizes and peak concurrency with AIPerf, opt in explicitly:

```bash
infercrane replay coder-production \
  --execute --acknowledge-cost --revision candidate
```

Execution is an AIPerf approximation, not a reproduction of prompt semantics or exact arrival timing.
The distinction is preserved in output and evidence.

An [optimization campaign](/features/optimization#how-a-campaign-measures-candidates) bound to a
trace digest goes further. It renders each request's input and output token counts as an AIPerf
`mooncake_trace`, and it keeps requests that share system messages, or continue a session, sharing
their leading prompt blocks. Arrival timing is still not replayed. Prompt content is synthetic unless
the operator supplies a [prompt corpus](/features/optimization#how-a-campaign-measures-candidates) of
real text to compose the requests from; Replay itself never stores prompts.

## Capacity intelligence

```bash
infercrane capacity --window 720h
```

Capacity Intelligence groups this tenant's observed lifecycle attempts by provider adapter, runtime,
compute mode, region, and GPU. It reports sample counts, success rate, normalized capacity/runtime
failures, and p50/p95 operation duration. It does not claim global availability or combine customer data.

## Artifact placement

The artifact cache contract records short-lived provider-native observations (`present`, `prefetching`,
`missing`, or `unknown`). Prefetch requests are durable and idempotent, but execution belongs to the
selected infrastructure adapter. InferCrane does not implement a model CDN or download protocol.

The AWS adapter verifies immutable encrypted EBS snapshots. The GCP adapter verifies zonal
Persistent Disks whose description binds the exact model-identity digest. The Kubernetes adapter
verifies bound, multi-reader PVCs with the same identity binding. All three attach or mount storage
read-only; real provider cache-hit timing and node-local Kubernetes cache execution remain separate
qualification work.

<Warning>
Cache observations expire after at most 24 hours. Missing or stale evidence must never be treated as a
cache hit or a readiness guarantee.
</Warning>

## Current boundary

Local qualification proves capture privacy, deterministic digests, tenancy, aggregation, and delegated
prefetch semantics. Real cache behavior and capacity distributions require the consolidated provider
qualification run.
