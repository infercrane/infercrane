# Edge-case hardening progress

## Scope

This work attacks the existing InferCrane product as a distributed control plane. It does not add providers, runtimes, APIs, or product capabilities.

## Baseline

- Baseline commit: `561c3ce`
- Worktree was clean and Docker Compose had no running or stopped project services.
- The prior whole-product qualification suite was green; this is treated as a starting point, not proof of edge-case safety.

## Investigation disposition

All CRITICAL/HIGH, DIRECT/PLAUSIBLE hypotheses that are locally testable have a recorded outcome. Every reproduced local defect has a regression test and a passing fix. Provider-native, real GPU/runtime, multi-host, network-topology, and long-duration behavior remains outside the local proof boundary and is specified in `manual-edge-cases.md`.

## Completion rule

The local investigation is complete only when the rebuilt full developer check is green and the final report continues to match the ledger. External qualification remains separate and must never be inferred from fixture results.
