## Failure-taxonomy disposition

| Class | Highest-risk local disposition | Remaining external uncertainty |
|---|---|---|
| A. Distributed operations | Lost response, duplicate/reordered retry, lease expiry, stale owner, cancellation/success, delete/create ordering, and 64-worker contention are covered by OP-001–OP-008 and provider conformance. | Real provider acknowledgement loss and clock/network behavior. |
| B. Database/transactions | Atomic enqueue, semantic idempotency, database-clock fencing, cancellation ordering, serialized/checksummed migrations, every historical prefix, restore, and concurrent startup pass on PostgreSQL. | Managed PostgreSQL failover latency and customer RTO/RPO. |
| C. Reconciliation | Per-deployment isolation, orphan ownership, eventual delete, restart, route publication ordering, and stale Kubernetes generation are covered. | Long real-provider observation delays and foreign operator interference. |
| D. Autoscaling/capacity | Bounds, hysteresis, cooldown, stale/missing metrics, partial failure isolation, durable 1→2→1, pending scale intent, and generation-safe scale-down pass locally. | GPU allocation latency, quota/stock changes, and heterogeneous real readiness. |
| E. Routing/streaming | Generation state-machine fuzz, pinned streams, client cancellation, no stream retry, redirect rejection, router restart, and drain fencing pass locally. | Real runtime/TCP/proxy buffering and long GPU generation. |
| F. Release/revisions | Immutable candidates, bad candidate cleanup, atomic guarded promotion, stale candidate rejection, rollback restart, monitor fencing, passport binding, and missing evidence fail closed. | Real candidate performance/cost evidence and long observation windows. |
| G. Serverless | Lost create response, semantic create validation, zero-worker route semantics, cold/warm evidence freshness, cancellation, eventual delete, and orphan cleanup pass fixtures. | RunPod endpoint/worker timing and billing semantics. |
| H. Provider/API | 429/timeouts/5xx, malformed/truncated/semantic success, auth errors, output bounds/redaction, adoption, pagination/inventory contracts, and eventual delete are covered at deterministic boundaries. | Provider-specific undocumented states/API changes. |
| I. Security | Tenant/RBAC/scopes, secret references, redirect credentials, webhook SSRF, bounded errors/subprocesses, strict JSON, TLS/mTLS configuration, signature binding, and dependency advisories are covered. | Customer network/IAM correctness, organizational passport key trust, and patched real vLLM qualification. |
| J. Quota/admission | Concurrent limits, cancellation/double release, queue bounds/timeouts, priority/output/request bounds, distributed reservation, policy reduction, and tenant failure isolation pass race/PostgreSQL tests. | Multi-host throughput and clock/network behavior at customer scale. |
