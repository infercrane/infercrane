# Production inference without the platform engineering.

Deploy, autoscale, benchmark, and safely update vLLM workloads on GPU infrastructure you control.

```bash Quick deployment
infercrane deploy Qwen/Qwen3-8B
```

InferCrane gives applications one OpenAI-compatible logical endpoint while durable control-plane operations provision, reconcile, scale, and safely replace the vLLM workers behind it. Kubernetes is not required.

## One product, two compute modes

<Tabs>
  <Tab title="Elastic">
    SkyPilot provisions vLLM replicas on RunPod. InferCrane reconciles desired capacity, routes only to ready workers, and fences scale-down before termination.

    ```bash
    infercrane deploy Qwen/Qwen3-8B \
      --cloud runpod \
      --gpu L40S \
      --min 1 \
      --max 4
    ```
  </Tab>
  <Tab title="Serverless">
    RunPod Serverless owns worker allocation and scale-to-zero. InferCrane preserves the logical endpoint, lifecycle evidence, cancellation, and cleanup.

    ```bash
    infercrane deploy Qwen/Qwen3-8B \
      --compute serverless \
      --cloud runpod \
      --gpu L40S \
      --max 4
    ```
  </Tab>
</Tabs>

<Note>
InferCrane v0.1 supports vLLM on RunPod. Real-provider acceptance is still in progress; consult [capability status](/project-status) before relying on experimental paths.
</Note>

## Evidence, not guesses

InferCrane records durable operation events, immutable model and revision identity, normalized request telemetry, benchmark reproduction metadata, and deterministic policy decisions. It does not fabricate provider pricing or timing boundaries that the provider does not expose.
